❓ Como usar a conferência de códigos

A página compara cada código da planilha do cliente com a base de perfis da FC. Você confere pelo desenho e decide, item por item. Passe o mouse em qualquer botão para ver o que ele faz.

1. Escolha a aba

  1. Em conflito: o código do cliente aponta um perfil e o código que ele compra aponta outro. Comece por aqui.
  2. Sem comparação: o perfil existe, mas só uma extrusora tem ele na base.
  3. Código que compra fora da base: achou o perfil pelo código de mercado, mas o código que o cliente compra (ex.: Texa T25002) não está nele.
  4. Não encontrados: nem o código do cliente nem o que ele compra estão na base.
  5. Certos: código e compra no mesmo perfil. Confira alguns por amostragem.

2. Confira o desenho

  1. No topo do cartão estão o código do cliente, o peso da planilha e o que ele compra hoje.
  2. O desenho com borda verde é o código do cliente ou o que ele compra.
  3. Clique no desenho para ampliar. Compare também o peso (kg/m) com o da planilha.

3. Decida

  1. 🔗 Mesmo perfil: unir os dois lados são o mesmo perfil. Leva o código que o cliente compra para o perfil do código dele. Grava na base na hora.
  2. ➕ Incluir coloca o código que o cliente compra no perfil mostrado, com o peso informado. Grava na base na hora.
  3. 📄 Erro na planilha o código do cliente está ligado ao produto errado na planilha dele. Escreva na observação qual é o certo.
  4. ✅ Perfis diferentes · está certo são perfis diferentes mesmo (ex.: tubo com parede diferente). Fica como está.
  5. ✅ Conferido e ❌ Está errado nas abas Certos e Sem comparação. "Está errado" manda o item para a aba Em conflito.
  6. Nos não encontrados, digite o código certo e clique em 🔎 Procurar. Se achar, inclua ou registre "o certo é…".

4. Feche a conferência

  1. Cada aba mostra quantos itens já foram decididos. Os que faltam aparecem primeiro.
  2. Errou? Clique em desfazer. Unir e incluir já foram gravados na base: para voltar, edite o par na Conversão de códigos.
  3. No fim, clique em 📋 Copiar resumo das decisões e mande para o Claude corrigir a lista de códigos do cliente.
